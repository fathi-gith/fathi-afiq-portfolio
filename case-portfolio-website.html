Personal Portfolio Website

A personal portfolio website designed to showcase my creative experience, selected projects and professional background through a structured and user-friendly digital experience.

The challenge

Traditional portfolio websites often require extensive scrolling and make it difficult for recruiters to find relevant information quickly. I wanted to create a more organised experience that presents my profile, experience and creative work in a clear and accessible way.

Design approach

Inspired by modern portfolio interfaces, I developed a corporate-inspired visual direction with a dark theme, glassmorphism elements and a consistent blue accent palette.

Dark themeGlassmorphismBlue accent paletteThree-panel layout

The interface follows a structured three-panel layout, keeping profile navigation accessible while presenting the main content and visual previews in dedicated sections. My priorities were clarity, accessibility and efficient navigation, allowing recruiters to explore relevant information without unnecessary scrolling.

Design and development

I established the visual direction, information architecture, navigation flow and user experience. The website was developed using HTML, CSS and JavaScript, with AI-assisted coding to support implementation and troubleshooting.

Challenges and problem solving

One of the main challenges was understanding the HTML structure and how individual code blocks controlled the portfolio gallery. Managing artwork entries, organising project categories and ensuring each visual appeared correctly required a better understanding of how the website's components worked together.

This process strengthened my understanding of front-end implementation and the relationship between design decisions and technical execution.

Project outcome

A personalised digital portfolio built around a structured navigation system and a recruiter-focused browsing experience, bringing my professional profile and creative work together in one platform.
